# Компоненты дизайн-кандидатов

| Компонент | Назначение | Правило для Android |
| --- | --- | --- |
| Заголовок страницы | Основной заголовок и краткий контекст | Масштабируемый текст, системные отступы, верхнее действие 48 dp |
| Нижняя навигация | Библиотека, коллекции, добавление, поиск, AI | Иконки с подписями, выбранное состояние в семантике |
| Поиск | Вход к полнотекстовому запросу | Текстовая подпись, поддержка клавиатуры и пустого запроса |
| Строка материала | Заголовок, тип и метаданные | Полная область нажатия, перенос текста, доступное описание |
| Фильтр формата | Отбор материалов по формату | 48 dp, выбранное состояние, адаптивная прокрутка |
| Плитка темы | Заголовок темы и объём | Переход к материалам, адаптивная сетка |
| Медиа-плитка | Просмотр материалов с превью | Область изображения, текстовая альтернатива |
| Контекстная панель | Продолжение чтения или работы | Один основной CTA, плоская поверхность со светлым оттенком |
| Раздел даты | Группировка истории | Видимая дата и доступный заголовок раздела |
| Строка истории поиска | Повтор запроса | Полная область нажатия и подпись, число результатов в тексте |

Источники предложений находятся в `concepts/*/index.html`, общие стили — в `concepts/library.css`. Компоненты эталона и состояние визуального контроля фиксируются после выбора владельца.
