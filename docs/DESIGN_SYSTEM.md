# Дизайн-система Android-first

## Визуальный стиль
Premium Soft Glass + restrained neumorphism; только светлая тема в базовом варианте. Не использовать тяжёлые градиенты и постоянное свечение.

## Токены (стартовые, требуют проверки)
Background #F7F9FD; Surface #FFFFFF; Primary #635BFF; Secondary #2E9CF5; Text #182238; Secondary Text #66748C; Border #E5EAF3; Success #17865A; Warning #B76A12; Error #C43D4A.

## Mobile UX
- Размеры в dp/sp, не фиксированные пиксели.
- Touch target минимум 48×48 dp.
- Базовые отступы 4/8/12/16/24/32 dp, поля ~16 dp.
- Шрифт с кириллицей, например Roboto; заголовки 22–24sp, секции 18–20sp, карточки 15–17sp, основной текст 14–16sp.
- Edge-to-edge, системные insets, клавиатура, масштаб текста, TalkBack.
- Пять основных точек навигации: Библиотека, Коллекции, Добавить, Поиск, AI.
- Контекстная панель на экранах чтения и редактирования.
- Режимы карточек: компактный список, расширенный список, визуальная сетка.
- Одна задача на экран, основные действия в зоне большого пальца.
- Уважать системное уменьшение анимации.

## Визуальный QA
Сначала 10 разных концепций главного экрана, затем утверждение направления, затем 28 отдельных экранов. Для утверждённых артефактов фиксировать SHA-256 и Reference Lock. Не считать изображение работающим интерфейсом.
