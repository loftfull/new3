Android 15, 780 × 1690, 320 dpi, масштаб шрифта 1.0. Сохранено семь записей, включая ссылку для проверки офлайн-перезапуска. В блоке «Недавние» воспроизведены шесть заголовков эталона. Сценарий проверил их порядок, отсутствие уведомления поверх списка, размер изображения и наличие навигации. Фактический счётчик и метаданные берутся из Room.

- Android QA: 2 app + 12 core, 0 ошибок, 0 провалов, 0 пропусков. Офлайн-перезапуск сохранил исходный URL.
- SHA-256 исходного снимка: `d63249b98af31e22fed2e157f46746558a6a60db505baa2c425314e9d7ba2a70`.
- SHA-256 локального debug APK: `1105498c99e91fa887f916cfed76364396cca0bbfaa6cc0a7819cfe4eac66221`. CI собрал APK из той же ревизии со своей debug-подписью.
- Независимый критик подтвердил шесть читаемых строк, отсутствие перекрытия, контуры иконок и пропорции нижней навигации.
- Visual QA: REVIEW. Текст заголовка примерно на 31 px выше эталона. Поле поиска сохраняет высоту, но находится на 20 px выше при измерении белой поверхности по x=550. Перенос видеозаголовка и оттенки части иконок различаются. Открыты проверки увеличенного шрифта, TalkBack и компактного заполненного экрана.
