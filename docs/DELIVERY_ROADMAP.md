# Delivery roadmap

## P1: Recover source and protect data
Identify canonical app source, branch, database, existing functionality. Backup and migration audit. Block any destructive rebuild.

## P1: Android capture/storage core
Share Sheet, URI handling, local persistence, ingestion status, offline save, error handling.

## P2: Design direction
10 separate main-screen concepts; owner approval; 28 separate screens; visual QA and accessible components.

## P2: Library UX
Collections, tags, source filters, list/grid, material detail, reading, notes, search.

## P2: AI pipeline
Extraction where permitted, optional summarization, classification, duplicate review, privacy, cost controls.

## P2: Knowledge workflows
Related items, AI assistant with source citations, project collections, analytics.

## P1 release gates
Android instrumentation tests, backup/restore round trip, data migration, visual screenshots, independent critique, signed build only after approval.

## GitHub usage
Issues for tasks and acceptance; PRs for reviewed changes; labels for priority/status/type; draft PR for incomplete work; Actions only for meaningful tests after source is available. Do not merge docs into main without review.
