## Обязательные состояния
Пустая библиотека; пустая коллекция; нет результатов; ошибка импорта; нет превью; нет сети; AI недоступен; конфликт синхронизации; подтверждение удаления; недостаточно места; восстановление; системные разрешения.

## Правило поставки макетов
design/screens/S01.png … S28.png — строго один полноформатный мобильный экран на PNG, без коллажей. Реальные PNG не созданы в этой ветке: не считать их готовыми. Для каждого экрана также нужны редактируемый исходник, описание состояний, переходов и проверка доступности.
